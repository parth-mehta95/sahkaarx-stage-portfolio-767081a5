# Add Exception Handling to Validators

## Task Brief
Refactor validators to handle edge cases, malformed input, and runtime errors gracefully with custom exceptions.

## Scenario
Your validators must handle unexpected input without crashing. Add defensive exception handling and custom error messages for debugging.

## Deliverables
- Custom exception classes for validation errors
- Validators with try-except blocks

## Success Criteria
- Validators catch and log all exceptions
- Custom exceptions provide clear error context
