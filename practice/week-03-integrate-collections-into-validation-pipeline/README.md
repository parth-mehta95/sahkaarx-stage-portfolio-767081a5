# Integrate Collections into Validation Pipeline

## Task Brief
Build a complete validation pipeline that uses collections to manage code samples, track validation history, and generate summary reports. Extend the capstone artifact.

## Scenario
Your team needs a production-ready validation pipeline that tracks all code samples and results. Integrate collections into the existing validators to create a queryable history.

## Deliverables
- Validation pipeline with collection-backed history
- Summary report generator

## Success Criteria
- Pipeline stores all validated code in collections
- Reports query and summarize validation results
